# Source and implementation notes

The eleven case studies follow the author's Figma portfolio. The website-design page is a layout reference; case imagery is exported from the original project pages. Artwork is not generated for this implementation.

- GlanceMap: original road and traffic signal, pilot iterations, final interface with the source's three dashed links to DG1–6, and a combined walking-study chapter.
- Color in Context: original Color Agent interface plus six independently exported numbered leader layers; the corresponding participant quotes and design implications appear as selectable HTML.
- Icon Colors: source comic narration and the three study evidence compositions, followed by the original icon guidelines and gradient examples.
- Ambulance Rush: SA Health reference map compared with the game map, and the original gameplay canvas with its six annotated features.
- Loofa Soup: original annotated gameplay layout, eight transparent characters, and 26 original transparent dish illustrations from the project design file.
- Her Sound, Re-sound: the author's third-chapter and POWER components, English guidance, eighteen original scenes, and the original selective erasure pattern. Canvas sampling is limited independently of image resolution.
- Our World: the current `OurWorld` project source was checked against the previously integrated animal PNGs, event records and candle implementation; their hashes match.
- Research projects retain source figures and verified numerical charts. VerseColor uses the portfolio's actual poem example for the word-block and connection interaction.

Image resolution follows native sources. SVG geometry and transparent source PNGs are preserved; Figma exports are used where they provide more detail. Lossless WebP is used for large raster assets. A low-resolution original cannot acquire missing detail from a larger export.

Font licenses are included in `dist/assets/fonts`; Three.js and the selected React excerpts retain their licenses beside their source. Historical concept art, rejected styles, complete old standalone game builds, local QA outputs, and unrelated application files are excluded from this repository.
